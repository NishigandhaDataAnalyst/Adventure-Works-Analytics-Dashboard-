# Adventure-Works-Analytics-Dashboard-

## Overview
Developed an end‑to‑end BI solution with data cleaning, modeling, and interactive dashboards to analyze sales, returns, revenue, and customer demographics, driving actionable business insights.

## Features
- **Data Preparation**: Cleaned and modeled data using **10+ fact and dimension tables**.  
- **Interactive Dashboards**: Bar charts, donut charts, waterfall charts, treemaps, slicers, and KPI cards.  
- **Advanced Analytics**: Implemented **20+ DAX measures** and calculated columns for drill-down and dynamic filtering.  
- **Business Insights**: Delivered insights on product performance, customer segmentation, and geographic distribution, driving **3.3% revenue growth (>$1.8M)**.

## How to Use
1. Download the `.pbix` file from this repository.  
2. Open it in **Power BI Desktop**.  
3. Explore interactive dashboards and apply slicers for deeper analysis.  

## Tech Stack
- Power BI Desktop  
- DAX (Data Analysis Expressions)  
- Data Modeling (Star Schema)  
- Adventure Works Dataset
